Beginner guide

How to build applications with Astro

Astro is a web framework for content-driven sites and apps. The beginner-friendly idea is simple: build pages from files, compose reusable components, and add JavaScript only to the parts that truly need it.

The basic workflow

Step 1

Start with a page

In Astro, each file in src/pages becomes a route. A simple .astro file can render a full page immediately.

Step 2

Use components for reuse

Astro components are HTML-first building blocks. They render to static HTML, which keeps the default output fast.

Step 3

Add interactivity only where needed

When a button, form, or widget needs JavaScript, hydrate just that piece with a client island instead of the whole page.

Quick basics

  • Install with npm create astro@latest.
  • Put pages in src/pages and shared layouts in src/layouts.
  • Use components for headers, cards, and repeated sections.
  • Keep JavaScript small: Astro ships zero client JS by default unless you add it.

1. Pages

Astro uses file-based routing. If you create src/pages/about.astro, it becomes /about.

2. Components

Components are reusable .astro files. They are great for nav bars, cards, and layout pieces. Astro renders them to HTML by default.

3. Interactivity

Add JavaScript only when needed. For example, use a small script or a hydrated framework component for a search box, toggle, or live form.

A tiny starter example

---
import Layout from '../layouts/Layout.astro';
---

<Layout title="My Astro App">
  <main>
    <h1>Hello, Astro!</h1>
    <p>Build the page with HTML and add JS only where needed.</p>
  </main>
</Layout>

That pattern is the heart of Astro: use a layout, write page content in HTML-like syntax, and keep the frontend lean unless a feature truly needs client-side behavior.

Best next step

After this, try building a homepage, an about page, and one interactive widget. That gives you enough Astro to ship a small site without overcomplicating the stack.
